# 🧾 Gestor de Informações Adicionais para NF

## 💡 Problema
A emissão de Notas Fiscais exige a inclusão de textos legais, dados bancários e instruções de entrega específicas conforme o cliente e a tributação. Gerenciar esses textos em blocos de notas ou planilhas é ineficiente e propenso a erros de cópia crítica.

## 🚀 Solução
Uma aplicação desktop intuitiva que consolida todas as informações necessárias para faturamento em um só lugar. O sistema permite selecionar categorias (Impostos, Bancos, Clientes) via menus suspensos e gera instantaneamente o texto consolidado pronto para ser colado no ERP.

## 🛠️ Tecnologias
- **Python 3**: Linguagem base.
- **Tkinter**: Interface gráfica simples e ágil.
- **Pyperclip**: Integração automática com a Área de Transferência.

## ⚙️ Como executar
1. Instale as dependências: `pip install pyperclip`
2. Inicie o sistema: `python dadospnotafiscal.py`
3. Selecione as opções desejadas e clique em **OBTER RESULTADO**.
4. Use o botão **COPIAR RESULTADO** para levar o texto ao faturamento.

## 📈 Resultado
- **Padronização total**: Garante que o texto legal e financeiro esteja sempre correto.
- **Agilidade no Faturamento**: Redução Drástica do tempo de preparo de informações adicionais na nota.
- **Interface Segura**: Todas as regras fiscais de ICMS-ST, IPI e Isenções estão centralizadas.
