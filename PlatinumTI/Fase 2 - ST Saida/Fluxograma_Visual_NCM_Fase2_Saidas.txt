                  |  =========================================
                  |  SISTEMA CALCULA — 3 MODALIDADES
                  |  =========================================
                  |
                  |  [REVENDA — Acordo ST = SIM, Cons. Final = NAO]
                  |  +------------------------------------------+
                  |  | 1. VT = Valor Mercadoria + Frete         |
                  |  | 2. ICMS Próprio = VT x Alíq. Inter.     |
                  |  | 3. Base ST = VT x (1 + MVA%)            |
                  |  | 4. ICMS-ST = (Base ST x Alíq. Intra)    |
                  |  |             - ICMS Próprio               |
                  |  |    [se negativo → zera]                  |
                  |  | 5. Total NF = VT + ICMS-ST               |
                  |  +------------------------------------------+
                  |
                  |  [CONS. FINAL NAO CONTRIBUINTE — CFOP 6108]
                  |  +------------------------------------------+
                  |  | Preço digitado = valor SEM imposto       |
                  |  | 1. Novo Valor = Valor / (1 - Alíq.Intra)|
                  |  | 2. ICMS Próprio = Novo Valor x Alíq.Int.|
                  |  | 3. DIFAL = (Novo Valor x Alíq.Intra)    |
                  |  |           - ICMS Próprio                 |
                  |  | 4. Total NF = Novo Valor                 |
                  |  |    (imposto já embutido no preço)        |
                  |  +------------------------------------------+
                  |
                  |  [CONS. FINAL CONTRIBUINTE — CFOP 6403]
                  |  +------------------------------------------+
                  |  | 1. VT = Valor Mercadoria + Frete         |
                  |  | 2. ICMS Próprio = VT x Alíq. Inter.     |
                  |  | 3. Base Dupla = (VT - ICMS Próprio)     |
                  |  |               / (1 - Alíq. Intra)       |
                  |  | 4. DIFAL = (Base Dupla x Alíq. Intra)   |
                  |  |           - ICMS Próprio                 |
                  |  | 5. Total NF = VT + DIFAL                 |
                  |  +------------------------------------------+
